# zentao-pets

看！这里有从禅道里蹦出来的小家伙，正排着队等着搬进你的桌面安家。通过 [Codex](https://chatgpt.com/en/codex/) 或 [Petdex](https://petdex.crafter.run/) 一键领养，它们就会乖乖蹲在屏幕角落，陪你写代码、追 Bug、推需求——偶尔挥挥手、蹦一蹦，让工作的时光多几分甜。

## 阿道

阿道来了，他会发呆、会奔跑、会挥手打招呼；任务卡壳时陪你一起 emo，跑通了立刻原地蹦跶。把它请进桌面，工位瞬间热闹起来。

## 阿婵
